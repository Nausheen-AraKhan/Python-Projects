# NATO Alphabet Project

A simple Python project that converts each letter of a word into its corresponding **NATO phonetic alphabet** code word.

For example:

```text
Input: HELLO

Output:
H → Hotel
E → Echo
L → Lima
L → Lima
O → Oscar
```

## 🚀 Features

* Converts words into NATO phonetic alphabet code words
* Uses a CSV file containing the NATO alphabet
* Uses **Pandas** to read and process the data
* Handles user input dynamically
* Simple and beginner-friendly Python project

## 🛠️ Technologies Used

* Python
* Pandas
* CSV

## ⚙️ How It Works

1. The program reads the NATO alphabet data from the CSV file.
2. The CSV contains each alphabet letter and its corresponding NATO code word.
3. The user enters a word.
4. The program checks each letter of the word.
5. It finds the corresponding NATO code word.
6. The NATO alphabet words are displayed as the output.

### Example

```text
Enter a word: CODE

C → Charlie
O → Oscar
D → Delta
E → Echo
```
