# 🇺🇸 USA States Game

An interactive Python game that challenges players to name all **50 U.S. states**. As you correctly guess each state, its name appears on the map in the correct location. The game also generates a list of states you missed, making it a fun way to learn U.S. geography.

## 📌 Features

* 🎮 Interactive state guessing game
* 🗺️ Displays correctly guessed states on the U.S. map
* ✅ Prevents duplicate guesses
* 📊 Keeps track of your score
* 📝 Generates a `states_to_learn.csv` file containing states you missed
* 🐍 Built using Python's Turtle Graphics and Pandas

## 🛠️ Technologies Used

* Python 3
* Turtle Graphics
* Pandas
* CSV Files

## 🎯 How to Play

* A blank map of the United States will appear.
* Enter the name of any U.S. state.
* Correct guesses will appear on the map.
* Continue until all 50 states are guessed.
* Type **Exit** anytime to quit.
* A file named `states_to_learn.csv` will be created containing the states you didn't guess.
